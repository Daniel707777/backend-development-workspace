# Backend Development Resources

## Git and version control

- [Pro Git book](https://git-scm.com/book/en/v2) — A free, detailed guide to Git fundamentals and common workflows.
- [Git reference](https://git-scm.com/docs) — Official documentation for Git commands.

## HTTP and web fundamentals

- [MDN: An overview of HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Overview) — A clear introduction to HTTP requests, responses, and the client-server model.
- [MDN: HTTP response status codes](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Status) — Explanations of common status codes and when they are used.
- [RFC 9110: HTTP Semantics](https://www.rfc-editor.org/rfc/rfc9110) — The HTTP semantics specification, including methods, status codes, and headers.

## RESTful APIs

- [Microsoft REST API Guidelines](https://github.com/microsoft/api-guidelines) — Practical guidance for designing consistent REST APIs.
- [MDN: Making HTTP requests](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch) — Examples of sending requests and handling responses with Fetch.

## Security

- [OWASP API Security Top 10](https://owasp.org/www-project-api-security/) — Common API security risks and recommendations for addressing them.
