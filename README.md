## Learning objectives

Throughout the course, I aim to:

- Use Git and version control confidently to track changes, work with branches, and maintain a useful project history.
- Write clear and reliable backend scripts, and improve my debugging and problem-solving skills.
- Apply advanced scripting techniques to practical backend tasks.
- Understand how RESTful APIs are structured and how to handle requests, responses, and errors consistently.
- Build a stronger foundation by completing the exercises and projects for each course unit.
- Reflect on my progress, identify gaps in my understanding, and decide what to practice next.

## How I’ll use this repository

I’ll use this repository as a semester-long record of both my work and my learning:

1. **Keep work organized by unit.** I’ll put each unit’s exercises and projects in its corresponding folder and use its README to describe the work as it grows.
2. **Practice version control as I learn.** I’ll make focused commits to record meaningful milestones, review changes before committing, and use branches when a task benefits from working separately.
3. **Record progress and reflections.** I’ll update the [learning log](./learning-log.md) with what I worked on, what I learned, challenges and solutions, and what I plan to practice next.
4. **Collect useful references.** I’ll add relevant documentation and learning links to [resources.md](./resources.md), and consult the [Git cheat sheet](./git-reference.md) when I need a command reminder.
5. **Review and improve.** As I finish each unit, I’ll revisit the work, note areas to strengthen, and apply feedback and lessons in later exercises and projects.

By the end of the semester, this repository should show my progress from foundational version control and scripting through advanced scripting and API development.
